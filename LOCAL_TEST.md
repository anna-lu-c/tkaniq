# Локальный запуск через npm

Нужен Node.js 18 или новее с npm.

1. Распакуйте архив.
2. Откройте PowerShell или Терминал в папке, где находится package.json.
3. Windows: `npm.cmd run dev`. macOS / Linux: `npm run dev`.
4. Откройте адрес из терминала, обычно http://127.0.0.1:5173/.

Устанавливать зависимости через npm install не нужно: сервер использует только Node.js. Терминал оставьте открытым. Остановка — Ctrl+C. После правок обновляйте страницу браузера; автоматической перезагрузки нет.

Для первоначальной загрузки нейросети нужен интернет. Фото обрабатывается в браузере. Для проверки пройдите путь: инструкция → фото → три варианта → восемь вопросов → результат. Проверьте справочник и возврат к исследованию.

Не запускайте BAT-файл из прежнего архива. Сайт пока не опубликован.
