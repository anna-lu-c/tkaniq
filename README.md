# ТканIQ

Учебный анализатор, рассчитанный прежде всего на телефоны. Без аккаунтов и чата: фото → три гипотезы → восемь вопросов → предварительный результат. Фото для анализа обрабатывается в текущей вкладке и не загружается в репозиторий.

## Файлы проекта
| Файл | Назначение |
| --- | --- |
| index.html | Страница |
| styles.css | Оформление |
| app.js | Анализатор и переходы |
| catalog.js | Загрузка и проверка JSON |
| data/fabrics.json | Шесть карточек с описаниями, свойствами, путями к фото |
| data/questions.json | Тексты восьми вопросов и подсказки |
| assets/images/fabrics/ | Фотографии справочника |

## Добавить фотографии карточек через GitHub
1. Откройте папку `assets/images/fabrics` в репозитории.
2. Нажмите Add file → Upload files. Загрузите снимки с простыми именами латиницей, например `cotton.jpg`, `cotton-closeup.jpg`. Сохраните Commit changes.
3. Откройте `data/fabrics.json`, нажмите карандаш редактирования.
4. Найдите карточку с `"id": "cotton"`. Замените её `"images": []` на:

```json
"images": [
  {
    "src": "assets/images/fabrics/cotton.jpg",
    "alt": "Общий вид хлопчатобумажного образца",
    "caption": "Общий вид. Фотография команды проекта."
  },
  {
    "src": "assets/images/fabrics/cotton-closeup.jpg",
    "alt": "Переплетение нитей хлопчатобумажного образца крупным планом",
    "caption": "Крупный план того же образца."
  }
]
```

5. Сохраните изменения. После обновления GitHub Pages фотографии появятся на сайте. Первое изображение используется в списке карточек, все — внутри карточки.

Пример подписей используйте только если они соответствуют вашим снимкам. Если состав образца не подтверждён, прямо укажите это в подписи. Можно добавить поле `caption` с данными об авторе и подтверждении состава. Поддерживаются JPG, JPEG, PNG, WebP. Рекомендуется 1200–1600 пикселей по длинной стороне, до 500 КБ на снимок. Регистр букв в имени файла и JSON должен совпадать. Не используйте пробелы и кириллицу в именах файлов.

## Изменить содержание
В `data/fabrics.json` редактируются `name`, `shortDescription`, `visibleFeatures`, `limitations`, `properties` (`touch`, `crease`, `water`, `usage`).

Шесть служебных id: `cotton`, `linen`, `wool`, `silk`, `viscose`, `acetate`. Их нельзя переименовывать: они связаны с анализатором. `group`: `natural` или `chemical`. Для фото пока оставлены пустые массивы — эталонные снимки не предоставлены.

В `data/questions.json` можно менять формулировки `text`, `hint`, `why` и отображаемые подписи ответов. Не меняйте id вопросов и служебные значения ответов: они связаны с правилами. Новые классы и вопросы требуют изменения логики. После последнего элемента JSON не ставят запятую. Если JSON повреждён, сайт покажет ошибку загрузки вместо неполного справочника.

## Публикация
Создайте публичный репозиторий `tkaniq`, загрузите все файлы и папки с сохранением структуры. `index.html` должен находиться в корне. Settings → Pages → Deploy from a branch → main → /(root) → Save.
Адрес после публикации: https://ИМЯ.github.io/tkaniq/.

Если загружаете через браузер, распакуйте ZIP и перетащите его содержимое в окно загрузки GitHub: загружать сам ZIP вместо файлов сайта не нужно.

## Локальный просмотр
В папке с package.json выполните `npm.cmd run dev` (Windows) или `npm run dev` (macOS/Linux). Откройте адрес из терминала. Нужен Node.js 18+. Зависимостей нет, npm install не требуется. Подробнее в LOCAL_TEST.md.

## ИИ
Transformers.js 3.8.1 и Xenova/clip-vit-base-patch32, WASM q8. При первом анализе библиотека и модель загружаются из внешних источников. Фото анализируется локально; свободные запросы и поиск в интернете отсутствуют. Перед анализом фото уменьшается на устройстве до 1280 пикселей по длинной стороне.

CLIP не обучали специально для этих шести видов. Это сравнение изображения с фиксированными описаниями, а не подтверждение состава. Чек-лист применяет экспериментальные правила к исходным трём гипотезам. Ответ «Не знаю» не меняет оценки. Смеси и другие ткани возможны.

## Проверка
Проверены синтаксис, JSON, соответствие id, логика чек-листа и отчёта. Загрузка модели и работа с реальными фото на телефонах ещё требуют проверки: браузерный предпросмотр в среде разработки недоступен.
