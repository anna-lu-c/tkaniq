# Фото для шести карточек

Подходит для tkaniq_npm(1).zip и версии с патчем чек-листа. Код анализатора и чек-листа не заменяется.

1. Распакуйте содержимое этого архива в папку сайта, где находится package.json. Папки assets, data и scripts должны объединиться с существующими.
2. Откройте НОВЫЙ терминал в папке сайта (в старом можно оставить работающий npm.cmd run dev).
3. Выполните:

   node scripts/apply-fabric-photos.mjs

4. В браузере нажмите Ctrl+F5 и откройте «Виды тканей».

Скрипт обновит только фотографии и источники в data/fabrics.json. Ваши тексты и ранее добавленные изображения сохранятся; скачанное фото станет первым в карточке. Перед записью автоматически создаётся резервная копия fabrics.backup-ДАТА.json. Повторный запуск не дублирует фотографии.

Все шесть JPG лежат внутри проекта: сайт не зависит от внешних ссылок для их показа. Сведения об авторах и лицензиях отображаются в подписях и на странице http://127.0.0.1:5173/photo-sources.html (если сервер выбрал другой порт, замените его).

Ограничения: это справочные иллюстрации, не подтверждённые эталоны. Фото rayon в карточке вискозы имеет размер 300 × 200 и не уточняет технологию изготовления; лабораторно подтверждённым вискозным образцом его считать нельзя. Для проверки точности используйте свои образцы с подтверждённым составом. Интернет-фотографии не меняют модель ИИ.

При публикации сохраняйте авторство и ссылки на лицензии. Для изображений CC BY-SA уменьшенные версии распространяются по той же лицензии; эти лицензии относятся к соответствующим фото, а не автоматически ко всему программному коду.
