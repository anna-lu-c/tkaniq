# Фотографии тканей
Загрузите сюда свои JPG, PNG или WebP и укажите пути в data/fabrics.json.
Примеры имён: cotton.jpg, linen.jpg, wool.jpg, silk.jpg, viscose.jpg, acetate.jpg.
Файлов с этими именами пока нет. Сайт показывает заглушки, пока поле images пустое.
Пошаговый пример с двумя фото находится в корневом README.md.
